# kobi

一个**纯本地运行**的安卓课程表应用。

核心价值只有一句话：**每节课开始前 1 小时，把下节课的课程名与地点推到手机通知栏。**

不联网、不注册、不上传任何数据。所有课表数据只存在手机本地的 SQLite 里。

---

## 功能

| 模块 | 功能 |
|---|---|
| 课程数据 | 增删改查、多时段（一门课可有多个上课时段） |
| 周次 | 周次范围 + 单双周（内部用位掩码表示，决定某周是否有课） |
| 冲突检测 | 同一天、节次重叠、周次相交时给出提示（**只提示不阻止**——大学课表本身存在合法冲突） |
| 批量导入 | CSV、粘贴课表纯文本、`.ics` 日历文件 |
| 周课表网格 | 时间 × 星期，支持连堂课程跨节次合并 |
| 列表视图 | 按「今天 / 明天 / 本周」分组 |
| 定时提醒 | 课前 1 小时准点触发（核心） |
| 通知呈现 | 动态倒计时 / 分段进度 / 自定义布局 三种样式 |
| 权限自愈 | 权限自检面板、开机重排闹钟 |

### 明确不做

- **教室路线指引**：通知中只展示教室文字信息，不做路线跳转。
- 教务系统自动抓取：需要上交教务账号密码，与《个人信息保护法》冲突，且有法律风险。
- 小米超级岛接入：需要企业资质与逐场景审核，个人开发者基本走不通。
- 常驻后台保活：违反应用商店生态政策，且厂商后台策略本身禁止。

## 构建（重要）

**本项目不在本地构建**，全部通过 GitHub Actions 编译。

```
推送到 main 分支  →  自动触发 .github/workflows/build-apk.yml  →  产出 APK
```

1. 打开仓库的 **Actions** 页面，等 `Build kobi APK` 跑完（首次约 3～6 分钟）。
2. 进入该次运行，在页面底部 **Artifacts** 下载 `kobi-apk`。
3. 解压得到 `kobi-debug.apk` 与 `kobi-release.apk`。

也可以在 Actions 页面手动触发（`workflow_dispatch`）。

### 为什么不在本地构建

本机没有安装 JDK、Android SDK 与 Gradle，且项目刻意不引入需要本地工具链的步骤。CI 用的是一套已验证可用的版本组合：

| 组件 | 版本 |
|---|---|
| JDK | 17 (temurin) |
| Gradle | 8.9 |
| Android Gradle Plugin | 8.7.3 |
| Kotlin | 2.1.0 |
| KSP | 2.1.0-1.0.29 |
| Compose BOM | 2025.01.00 |
| Room | 2.7.1 |
| compileSdk / targetSdk / minSdk | 35 / 35 / 26 |

## 安装与首次使用

1. 把 APK 传到手机安装（需允许「安装未知来源应用」）。
2. 打开应用，**授予通知权限**。
3. 进「设置」页，按面板逐项完成引导：
   - 通知权限
   - **精确闹钟权限**（设置 → 应用 → 特殊应用权限 → 闹钟和提醒）
   - 省电策略设为**无限制**
   - 关闭电池优化
   - 允许**自启动**（小米：安全中心 → 应用管理 → 自启动）
   - 在最近任务里**锁定**本应用卡片
4. 录入或导入课表。

> 这些设置不是可选项：漏掉任何一项，提醒都可能被延迟或根本不出现。

## 签名说明

`app/kobi.keystore` 是仓库内的**固定签名**（PKCS12，密码 `android`，别名 `androiddebugkey`），debug 与 release 都使用它。

这样做的目的是让 CI 每次构建出的证书指纹保持稳定，便于反复覆盖安装。**这是个人自用配置，不是安全的生产签名方案**——若要上架应用商店，必须换成你自己的正式签名并妥善保管密钥。

---

## 已知限制

1. **最重要的前提**：小米等厂商对「应用在后台发送本地通知」有系统级限制（默认可能拒绝，且用户设置里找不到开关）。本应用已按规范实现，但**能否按时送达必须在真机上实测确认**。若收不到，可考虑接入厂商推送通道。
2. 应用被杀后无法主动通知用户：厂商的省电机制可能清理后台进程，系统不提供「被清理时通知用户」的途径，只能靠上述白名单设置降低概率。
3. 批量导入的解析器是容错式的：解析不了的行会被跳过并记录，不会中断导入，但也不会智能纠错。

## 通知的三种样式

| 样式 | 用法 |
|---|---|
| **动态倒计时** | 通知栏时间戳位置显示真实跳动的倒计时，由系统自刷新（不占用应用资源、不受通知更新限流影响） |
| **分段进度** | 每段代表一节课，标记当前时刻；用于「上课进行中」状态 |
| **自定义布局** | 内容区自绘成整周课表网格，用于总览 |

每条通知最多 3 个快捷操作按钮（Android 的硬限制）。
